## Using Templates

### Quick Application

1. **Navigate to Templates Tab**
   - Click "Templates" in the right panel

2. **Browse Templates**
   - Scroll through 15 templates
   - View thumbnail, name, and description
   - See orientation badge (horizontal/vertical/grid)
   - Check element count

3. **Apply Template**
   - Click any template card
   - Elements instantly applied to canvas
   - Success notification appears

4. **Customize**
   - Switch to Layout tab to adjust positions
   - Use Properties tab for colors and effects
   - Add actual content via Asset panel

---

## Template Details

### Orientation Types

**Horizontal** (Blue Badge)
- Side-by-side layout emphasis
- Wide screens optimized
- Good for comparisons and narratives

**Vertical** (Green Badge)
- Top-to-bottom flow
- Mobile-friendly
- Good for storytelling and sequences

**Grid** (Purple Badge)
- Multi-element arrangements
- Gallery-style layouts
- Good for showcasing multiple items

### Element Counts

Templates range from **3 to 6 elements**:
- **3 elements**: Simple, focused layouts
- **4 elements**: Standard layouts with title, main content, footer
- **5 elements**: Rich layouts with multiple content areas
- **6 elements**: Complex grid layouts

## Customization After Application

### Immediate Adjustments (Layout Tab)

After applying a template, you can:

1. **Position Elements**
   - Adjust X, Y coordinates
   - Modify width and height
   - Change rotation angle
   - Update z-index for stacking

2. **Add/Remove Elements**
   - Click "Add Element" buttons
   - Remove unwanted placeholders
   - Duplicate existing elements

3. **Auto-Align**
   - Use Horizontal distribution
   - Use Vertical distribution
   - Center all elements

### Visual Customization (Properties Tab)

1. **Colors**
   - Change app colors (icon, text, background)
   - Apply blend modes

2. **Effects**
   - Add transitions
   - Enable blur or tint effects

3. **Content**
   - Upload actual images for image placeholders
   - Upload videos for video placeholders
   - Add audio tracks

## Advanced Template Techniques

### Combining Templates

1. **Apply Base Template**
   - Choose closest match to vision

2. **Export Configuration**
   - Save as JSON

3. **Apply Second Template**
   - Get additional elements

4. **Merge Manually**
   - Copy specific element positions
   - Create hybrid layout

### Creating Template Variations

1. **Apply Template**
2. **Modify Significantly**
   - Change all positions
   - Add/remove elements
   - Adjust sizes
3. **Save as Preset**
   - Your custom variation is saved
   - Reuse across projects

### Responsive Adjustments

Templates are optimized for desktop (1000x800px canvas). For responsive designs:

1. **Mobile Adaptation**
   - Use "Mobile-First" template as base
   - Or scale down element widths
   - Stack elements vertically

2. **Tablet Adaptation**
   - Reduce padding
   - Adjust element sizes proportionally
   - Test with tablet device preview

## Template Best Practices

### Choosing the Right Template

**Consider Your Content:**
- Single video? → "Video + Description" or "Hero Video"
- Multiple images? → "Gallery Grid" or "Masonry"
- Mix of media? → "Split Screen" or "Magazine"
- Tutorial/lesson? → "Video + Sidebar" or "Dual Sidebar"
- Simple showcase? → "Centered Slideshow" or "Portfolio"

**Consider Your Audience:**
- Mobile users? → "Mobile-First" or vertical templates
- Desktop users? → Horizontal or grid templates
- Mixed audience? → Vertical templates (more responsive)

**Consider Your Goal:**
- Engagement? → Hero or asymmetric layouts
- Information? → Sidebar or magazine layouts
- Showcase? → Gallery or portfolio layouts
- Narrative? → Stacked or vertical layouts

### Template Workflow Tips

1. **Start with Template**
   - Don't build from scratch
   - Choose closest match

2. **Apply Early**
   - Apply template before adding content
   - Easier to customize structure first

3. **Iterate Quickly**
   - Try multiple templates
   - See what works best
   - Templates are non-destructive (can reapply)

4. **Save Custom Variations**
   - Modified a template perfectly?
   - Save as preset for reuse

## Troubleshooting

### Template Not Applying
**Problem**: Clicked template but nothing happened
**Solution**: 
- Check browser console for errors
- Refresh page and try again
- Try a different template

### Elements Overlapping
**Problem**: Template elements overlap
**Solution**:
- Switch to Layout tab
- Adjust X, Y positions manually
- Use "Auto Align" to redistribute

### Template Doesn't Fit Content
**Problem**: Too many/few elements
**Solution**:
- Add elements manually (Add Element buttons)
- Delete unwanted elements (× button)
- Adjust element sizes to fit content
