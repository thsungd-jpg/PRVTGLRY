# PWA Builder - Private Gallery

A powerful visual editor for creating and customizing Progressive Web Apps (PWAs).

## Quick Start with VS Code Simple Browser

This repository is configured to open the app directly in VS Code's Simple Browser for a seamless development experience.

### Using VS Code Tasks

1. **Open Command Palette**: `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac)
2. **Run Task**: Select "Tasks: Run Task"
3. **Start Servers**: Choose "Start All Servers"
4. **Open Simple Browser**: 
   - Press `Ctrl+Shift+P` again
   - Type "Simple Browser: Show"
   - Enter URL: `http://localhost:3000`

**Or use the keyboard shortcut**: `Ctrl+Shift+B` after servers are running.

For detailed setup instructions, see [VSCODE_SIMPLE_BROWSER.md](./VSCODE_SIMPLE_BROWSER.md)
